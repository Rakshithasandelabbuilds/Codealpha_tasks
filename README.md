# CodeAlpha Python Programming Tasks

This repository contains four Python projects completed as part of the **CodeAlpha Python Programming Internship**.

## Projects

### 1. Basic Chatbot — `chatbot.py`
A simple rule-based chatbot that responds to user messages with predefined replies.

### 2. Hangman Game — `hangman.py`
A word-guessing game where the player tries to guess a hidden word within a limited number of attempts.

### 3. Stock Portfolio Tracker — `stock_portfolio_tracker.py`
Calculates the total value of a stock portfolio using stock prices and quantities entered by the user.

### 4. Email Extractor — `email_extractor.py`
Extracts email addresses from a text file and saves the results to an output file.

**Note:** The Email Extractor requires the sample input text file included in this repository. Keep it in the location expected by the script when running the program.

## Technologies Used
- Python 3
- Basic programming concepts
- Loops, functions, and conditional statements
- String processing and file handling

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the desired Python file using `python filename.py`.

## Purpose
These projects demonstrate practical Python programming skills and problem-solving through small, hands-on applications.
